# Olist E-Commerce Analytics Hackathon

Analysis of Olist marketplace data (Sep 2016–Oct 2018) covering marketplace 
performance, delivery satisfaction, geography, category performance, payment 
behavior, and root causes of customer dissatisfaction.

## Contents
- `olist_analysis.ipynb` — full analysis notebook
- `Olist_Analysis_Report.docx` — written report with findings and recommendations

## Data source
Brazilian E-Commerce Public Dataset by Olist (Kaggle), CC BY-NC-SA license.
Original dataset: kaggle.com/datasets/olistbr/brazilian-ecommerce
